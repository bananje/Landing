# Дизайн-система «Лайм и чернила»

Светлый стиль по папке `РЕФЕРЕНСЫ`: белый и светло-серый фон, один кислотный лайм, чёрные кнопки, ч/б фото, хромовое 3D. Тема одна, светлая.

## Файлы

| Файл | Что внутри |
|---|---|
| `tokens.css` | Цвета, шрифты, размеры, отступы, скругления, тени, движение. Только CSS-переменные |
| `components.css` | Базовые стили и компоненты (кнопки, плашки, плитки, шаги, метрики, декор) |
| `index.html` | Живой справочник. Открывать через локальный сервер, например `python3 -m http.server` из корня проекта, затем `/design-system/index.html` |

## Подключение

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Onest:wght@300;400;500;600&family=Unbounded:wght@500;700&display=swap&subset=cyrillic">
<link rel="stylesheet" href="design-system/tokens.css">
<link rel="stylesheet" href="design-system/components.css">
```

Старые `apple-design.css`, `DESIGN.md` и `style/` относятся к прежнему тёмному стилю. Вместе с новой системой их не подключать: у них пересекаются имена классов и переменных.

## Цвета

| Токен | Значение | Где |
|---|---|---|
| `--lime-500` | `#CCF52B` | Плашки, лаймовые плитки, кружок со стрелкой |
| `--lime-600` | `#B9F500` | Гигантские слова, лучи, искры. Не для текста |
| `--ink-950` | `#0B0B0B` | Заголовки, основные кнопки, тёмная плитка |
| `--paper-50` | `#F8F8F8` | Фон страницы |
| `--paper-0` | `#FFFFFF` | Карточки |
| `--paper-100` / `--paper-300` | `#F0F0F0` / `#D9D9D9` | Серая плитка / выделенная серая |
| `--ink-600` | `#6A6A6A` | Мелкий текст, контраст 5.3:1 на белом |
| `--ink-400` | `#8E8E8E` | Только вторая половина крупного заголовка |
| `--cobalt-600` | `#1B2FD8` | Один контрастный блок на страницу, не чаще |

В разметке использовать смысловые токены (`--bg`, `--surface`, `--text`, `--accent`), а не примитивы.

## Шрифты

- **Onest** 300–600: все заголовки, текст, кнопки, цифры. Есть кириллица.
- **Unbounded** 700: только гигантские декоративные слова. Не для абзацев и кнопок.
- Размеры плавающие (`clamp`): `--fs-ghost`, `--fs-display`, `--fs-h1`, `--fs-h2`, `--fs-h3`, `--fs-lead`, `--fs-body`, `--fs-small`, `--fs-micro`.
- Заголовки сжаты: `--tracking-display` −0.04em, `--tracking-head` −0.03em.
- Предлоги из одной-двух букв в заголовках склеивать с соседним словом через `&nbsp;`, чтобы они не повисали в конце строки.

## Правила

1. Лайм только заливкой под чёрным текстом или крупным декоративным словом. Мелкий лаймовый текст на белом не читается.
2. Заголовок в две краски: начало чёрное, окончание серое.
3. Над секцией лаймовая плашка со строчной подписью.
4. Номера «/01» только там, где порядок действительно важен.
5. В сетке одна лаймовая плитка и не более одной чёрной. Остальные белые или серые.
6. Фото только чёрно-белые.
7. На экран не больше одного крупного декора (слово, лучи или 3D).
8. Тени и обводки не вешать на каждую плитку.
9. Цифры клиентов и отзывы не придумывать. В справочнике значения вида «00%» это заглушки.

## 3D-объект

Хромовую звезду из референса можно собрать из существующих `hero-3d.js` и `models/saas-stars.glb`: заменить материал на хромовый с отражением светлой среды, фон канваса сделать прозрачным. В эту систему 3D пока не входит.
